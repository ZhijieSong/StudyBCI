# 数据获取说明

本仓库使用 **BCI Competition IV Dataset 2a**（Graz 工业大学公开数据集）。原始数据**不随仓库分发**，请自行下载后放入本目录。

## 下载

- 官方页面：https://www.bbci.de/competition/iv/
- Dataset 2a 下载入口（含训练/评估 GDF 与 desc_2a.pdf 说明）。

## 需要哪个文件

本次实测用的是 **A01T.gdf**（受试者 A01 训练段）。下载后放到本 `data/` 目录并命名为：

```
data/A01T.gdf
```

如需跑其他受试者，替换为对应的 `A0xT.gdf` 即可。

## 记录参数（来自 desc_2a.pdf）

- 22 个 EEG 通道（10-20 布局）+ 3 个 EOG 通道，采样率 **250 Hz**，单位 **µV**，16 bit 记录。
- 4 类运动想象：左手 / 右手 / 双脚 / 舌头。
- 记录时已做 0.5–100 Hz 带通 + **50 Hz 陷波**（左乳突参考）。
- 事件码：769–772 对应 4 类提示；1023 为专家标记的伪迹 trial 起点（提示在其后 2 s = 500 采样处）。

更完整的参数、通道序与范式时序见 `../docs/data.md`。
